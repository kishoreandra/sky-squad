SKY SQUAD HOME SERVER (Windows desktop)

1. Double-click START-SERVER.bat. If Windows asks about the firewall, click Allow.
   If Windows says "Windows protected your PC", click More info > Run anyway.
2. Run the playit.gg program and make a UDP tunnel to local port 25001
   (full steps in the Sky Squad setup guide).
3. playit gives an address like  name.gl.at.ply.gg:12345
   In the game: Play with friends > Online rooms > Server > type that address > Save.
4. Create room / Join room. There is one room on a home server: everyone lands in it.

The first person in is the room leader (picks map, taps Start).
Keep the black window open while playing. Close it to stop.
